## 1. 对象表（`unity1x.py`）

ObjectInfo 20B/条：`+1..4 u32BE offset`、`+7..8 u16BE size`、`+12..13 u16LE typeID`、
`+14..15 u16LE classID`、`+19 u8 pathID 高字节`。数据区 `[16, metaStart)`。

## 2. AudioClip ✅

```
u32BE name_len | name | u32BE format | f32BE duration | u32BE freq
  | u32BE dataSize ×2(冗余双写) | 音频数据
format: 1=8bit PCM/mono  2=16bit PCM/mono  4=16bit PCM/stereo  5=OggVorbis
```
- PCM 样本**小端**（与文件大端相反）。
- **流式余量线性相邻、无间隙**：整段 = `raw[obj.offset + 4+namelen+20 : + dataSize]`。
- Ogg 按 `serial`(小端@+14) 聚合 9561 页 → 9 组重建（末页 EOS=True）。
- **无 MP3**：`ff f1` layer=00 reserved，非合法帧；46 个"MP3"实为 PCM。
- 脚本：`extract_audio_final.py` / `ogg_rebuild.py` / `verify_audio2.py` / `manifest_audio.py`。

## 3. Mesh ✅（本轮攻克）

UnityPy 只能解 179/823，且报 `read_unsigned short_array out of bounds`。
自研解析器 809/823：

```
name
m_LODData: [u32 L]{ LOD:[u32 n]{ MeshData:
    faces([u32 nf][nf×6B 三角形 v1,v2,v3 u16BE])
    strips([u32 ns][ns×2B 三角带 u16BE, 0xFFFF 重启]) }*n }*L
m_Vertices: [u32 V][V×Vector3f f32BE]
m_UV: [u32 U][U×Vector2f f32BE]
m_LocalAABB / m_CollisionTriangles / ...
```
- 顶点 float **大端**（PPC）。
- 几何在 faces（191 个）**或** strips（618 个）。
- 三角带解码 + 剔除退化三角形（缝合产生）。
- 定位 m_Vertices：faces/strips 之后的第一个 `[u32 V][V×float3]` 区块
  （faces 的 u16 解释为 float 是次正规数，天然排除）。
- 脚本：`mesh_extract4.py`；预览：`render_mesh.py` → `proof/mesh_preview.png`。

- `[0:4]`=enableTypeTree(1)，`[4]`=树总数（1 字节）
- `[5..]` 连续树列表：`[4B BE classID][type\0][name\0][6×int32 BE]`+DFS 子树（numChildren 隐式，无独立层级区）
- **脚本树 classID = -实例 pathID**（69/70 直接命中；1 例外 byteSize 兜底）
- 内置树 classID = Unity 类 ID（GameObject=1…MonoScript=115；**AudioClip=83** 非现代 58）
- 序列化全大端无对齐；MB base 17B = PPtr(8)+bool(1)+PPtr(8)；string = 长度前缀
- 排除错误假设：独立层级区（38234=4×3937+2×11243 纯数学巧合）、typeID 索引树根
