#### 音频格式定案（Unity 1.x AudioClip）
```
name_len(u32 BE) | name | format(u32 BE) | duration(float BE) | freq(u32 BE)
  | dataSize(u32 BE) ×2 (冗余双写)
  | 音频数据（紧跟其后，无间隙；流式余量也线性相邻）
format: 1=8bit PCM(mono)  2=16bit PCM(mono)  4=16bit PCM(stereo)  5=OggVorbis
```
- **PCM 样本为小端**（与 Mesh 的大小端相反！）
- Ogg 页在流区按 `serial`(小端@+14) 分组重建（`ogg_rebuild.py`，9561 页→9 组）

## ⏳ 待办：Mesh（classID 43，823 个）

### 已破解的结构（TypeTree 权威定义）
```
Mesh:
  string   m_Name
  Array    m_LODData: [SInt32 size, LOD...]
  vector   m_MeshData: [SInt32 size, MeshData:
              vector faces:  [SInt32 size, Face{UInt16 v1,v2,v3}]
              vector strips: [SInt32 size, UInt16 data]
              vector m_Vertices: [SInt32 size, Vector3f{x,y,z}]  ← 大端 float
              vector m_Skin: [...]
              ...（后续还有法线/UV/tangent 等）
           ]
```
- 头部：`name` 后 32B 为 uint16 字段序列，含顶点数/通道描述符对
- 顶点数据 = **大端 float32**（PPC 字节序）
- 尾部实测为 vec3 float 序列（m_Vertices 靠尾）

3. **流式余量**：大网格顶点数据有一部在流区（同音频，线性相邻）
4. `mesh_extract.py` 朴素启发式 → 0 成功，需按类型分别处理
