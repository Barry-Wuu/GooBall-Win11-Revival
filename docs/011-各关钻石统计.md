# 011 - 各关钻石统计

> 游戏内 HUD 只显示**当前关**的收集进度，不提供全游戏钻石总数。
> 本文由 `tools/level_diamonds.py` 直接从二进制资产统计，可复现。

## 数据来源

| 项 | 来源 |
|---|---|
| 关卡表（11 章 61 关） | `docs/evidence/il_all.txt` → `MapInfo::SetupLevels` 的 **Panther 分支**（`IL_0016`~`IL_0367`） |
| 场景文件号 | `AddLevel(name, index)` 的 `index + 3`（`level0/1/2` = 标题 / 章节选择 / 地图） |
| 钻石数 | `StarPickup` MonoBehaviour 实例逐关计数（`tools/bind_all_mb.py` → `mb_bind_all.json`，1447 个 MB 实例中成功绑定 1440） |

**关于 `isPanther` 分支**：`SetupLevels` 开头有
`Application::get_isPanther → brfalse IL_0368`。
前半（`IL_0016`~`IL_0367`）是完整的 **11 章 61 关**；后半（`IL_0368` 起）只有
6 关 3 章的演示子集（Welcome / Lagoon / Area 51 / Into the bowl / King of the hill / Quagmire）。
发布版实际用的是完整表 —— archive.org 留存截图里那张 11 章选关界面
（Introduction / Area 51 / UFO Crash Site / Montezuma / Space / Scream Park /
Underwater / Aztec Spacerace / Cruel World / Dementia / Evil Finale）即为其证。

## 说明

**0 钻石的 7 关**：`Into the bowl`(level12)、`Under The Sea`(level45)、
`Going Deeper`(level46)、`Triple bowls 'o fun`(level49)、`Roundabout`(level44)、
`Mount Goom`(level65)、`Eternal Spin`(level68)。
这些关卡场景里**没有 `StarPickup` 实例**，目标也只需 1~2 个 `GoalTrigger` ——
属于「纯技巧/竞速」关，不设收集物。

**未被关卡表引用的场景**（`level3`~`level68` 共 66 个场景里用了 61 个）：

| 场景 | 钻石 | 备注 |
|---|---|---|
| `level5` | 5 | 夹在 Lagoon(level4) 与 Area 51(level6) 之间，**被砍掉的隐藏关**，游戏内无法进入 |
| `level14` `level15` `level16` | 0 | 未启用（UFO Crash Site 章节前后空档） |
| `level52` | 0 | 未启用（Underwater 与 Aztec Spacerace 之间空档） |

**全库 `StarPickup` 实例共 268 个**，其中 262 个属于 61 个启用关卡，
5 个在未启用的 `level5`，1 个在 `mainData`（标题画面演示）。

**复现**：

```bash
python tools/bind_all_mb.py        # 生成 mb_bind_all.json（MB → 脚本类绑定）
python tools/level_diamonds.py     # 打印本表
```
